Ovaj sajt prati strukturu tvog dvokolonskog PDF CV-ja i sadrži ugrađen prekidač za srpski (`SR`) i engleski (`EN`) jezik u gornjem desnom uglu.

## Kako dodati slike?
1. Ubaci sliku u folder `images/` (npr. `projekat1.jpg`).
2. U `index.html` zameni `<div class="placeholder-inner">...</div>` sa `<img src="images/projekat1.jpg" alt="Opis">`.
